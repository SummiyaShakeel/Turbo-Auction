🏎️ Turbo Auction | Client Dashboard
The Next-Gen Interface for Distributed Bidding.

This repository contains the Client-Side Application for the Turbo Auction system. Designed with a high-fidelity "Mafia-style" aesthetic—featuring dark themes, Neon Cyan, and Emerald Green—this WPF dashboard allows users to connect to a Master Node and participate in live, high-stakes auctions.

💎 Cinematic Visuals
Neon Cyan (#00F0FF): Accentuating active bid states and interactive elements.

Emerald Green (#1F7735): Signifying successful bids and auction victories.

Dark Mode Interface: Optimized for focus and professional cinematography.

🛠️ Core Functionality
Real-Time Data Staging: Automatically receives vehicle specifications and high-resolution imagery from the Admin.

Dynamic Bid Logic: Increases current prices instantly and syncs with the server's global timer.

Automated Winner UI: Triggers a victory state if you hold the highest bid when the countdown hits zero.

🚀 Join the Auction (Teammate Guide)
1. Download the Package
Download the latest build provided by the Admin. Important: You must Extract All files from the ZIP folder before running the application to avoid crashes.

2. Launch the Client
Find the file named TurboAuctionWPF (Type: Application). Double-click to launch.

3. Authentication & Connection
On the login screen, enter the following credentials provided by the Admin:

User Identity: Your actual name (used for bid tracking).

Admin IP Address: The current session's IP (e.g., us.loclx.io or a public IP).

Assigned Port: The 5-digit session port (e.g., 8080).

4. The "Gatekeeper" Protocol
Once you click Request Access, wait for the Admin to admit you to the session. You will enter the dashboard once authorized.

🏗️ Technical Stack
Frontend: WPF (XAML) with cinematic styling.

Backend Logic: C# / .NET 8.0.

Communication: TCP Sockets for real-time state synchronization.
